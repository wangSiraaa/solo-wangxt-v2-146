# 分子结构编辑器（教学版）

纯本地运行的化学教学工具：Vue 3 + TypeScript 界面，RDKit.js(wasm) 负责解析、价态校验与规范化，SVG 画布显示与编辑结构，工程保存在浏览器 IndexedDB，**无后端、不上传任何数据**。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览构建产物
npm test           # Node 中的化学逻辑测试（真实 RDKit，60+ 断言）
```

## 功能与对应实现

| 需求 | 实现 |
| --- | --- |
| SMILES 导入 | `src/rdkit/service.ts` `importSmiles()`：RDKit 解析 → 生成 2D 坐标 → molblock → 前端图模型 |
| 修改键并更新分子图 | 画布中所有编辑（键级/芳香/楔形/原子/电荷/同位素）都改的是图模型（`src/chem/model.ts`），随即序列化为 V2000 molblock 交 RDKit 重新校验、规范化（`mutate()` → `analyzeGraph()`），不是只画线 |
| 普通/芳香/楔形键不同语义 | 模型中 `order` / `aromatic` / `stereo` 分列；写出为 molfile type 4 与 bond stereo 1/6/4；渲染分别为 实线组 / 实线+虚线 / 实心楔与虚线楔 |
| 隐式氢、电荷、同位素参与校验 | 全部由 RDKit sanitize 把关；电荷与同位素以 `M CHG` / `M ISO` 写入 molfile；隐式氢数取自 RDKit JSON 的 `impHs` 并显示在原子标签与分子式中 |
| 原始输入 vs 规范形式 | 导入面板并排显示原始输入与规范异构 SMILES，标注"一致/已规范化" |
| 解析失败定位并保留草稿 | `src/chem/smilesError.ts`：本地括号/环扫描 + 以 RDKit 为预言机的最长可解析前缀定位；出错字符高亮，输入框草稿保留，**不做任何近似替换** |
| 构造/立体异构比较 | `src/chem/compare.ts`：规范异构 SMILES → 同一；去立体（清楔形 + 坐标归零）后相同 → 立体异构；分子式相同 → 构造异构 |
| 导出再导入保持立体 | 校验面板内置"导出→再导入自检"：规范 SMILES 再导入、molblock 再解析、立体标签三重比对（测试覆盖手性 @ 与 E/Z 往返） |
| 工程保存 | `src/db/idb.ts`：IndexedDB 存 名称/草稿/molblock/规范式，可载入/删除 |
| 教学安全边界 | 示例均为常见无害分子（水、乙醇、乙酸、氨基酸、糖代谢相关小分子等），仅做结构表示与基本性质（分子式、分子量、HBD/HBA、TPSA、cLogP 等）观察，不提供合成或实验指导 |

## 编辑操作

- **选择/移动**：拖动原子（移动后重新校验，因为 2D 几何决定 E/Z）；Delete 键删除选中
- **键工具**（单/双/三/芳香/楔形/虚线楔）：点击已有键直接改类型；从原子拖出到另一原子成键、拖到空白处自动补一个碳
- **原子工具**：空白处点击加原子；点击已有原子改元素
- **选中项面板**：改元素/形式电荷/同位素；改键级/芳香/立体；"反转构型"（楔形上下对调 ⇔ 对映体）
- 楔形键窄端自动朝向连接度更高的原子（RDKit 只在窄端位于手性中心时感知手性）
- Ctrl+Z / Ctrl+Shift+Z 撤销重做

## 关键设计

- **RDKit 是唯一权威**：前端不做价态/芳香性猜测；校验失败时保留画布结构并给出局部价态提示（明确标注为"估算"），绝不替换成"差不多"的分子
- **V2000 molblock 是模型与 RDKit 之间的交换格式**：坐标、键级、芳香性、楔形、电荷（`M CHG`）、同位素（`M ISO`，4 字符定宽字段）都完整往返
- **E/Z 由坐标表达**：RDKit 的 molblock 不写双键 stereo 字段，因此"去立体比较"会同时清零坐标，避免几何被重新感知
